# GraphGuard opt-in AWS synthetic research sandbox — review ONLY

This **isolated** Terraform root is the safe alternative to the unreviewed costly `../main.tf` design with EKS, NAT, RDS, ElastiCache and MSK. Run `terraform init -backend=false && terraform validate` only in this directory. The root declares: one private, versioned, SSE-S3 S3 bucket; a Glue **metadata-only** catalog database; one Athena workgroup with a **1 GiB/query** scanned-data cutoff, and a narrow GitHub OIDC role bound to `repo:HuLaxx/GraphGuard:environment:analytics-review`. Data prefixes: `synthetic-datasets/`, `model-artifacts/` (OIDC role read-only), `research-results/`, and `athena-results/`. The role cannot mutate the model-artifacts prefix and cannot run Terraform.

**Zero actual AWS resources have been provisioned.** No API, ECS, Lambda, EventBridge, Step Functions, Glue ETL, CloudWatch alarm, Secrets Manager secret or hosted Neo4j is configured here. A passing `terraform validate` does not prove deployment or cost savings. Model provenance is still enforced locally by independently pinned hashes. Never upload customer data to this bucket.

Local-only acceptance: GitHub [P4 research Terraform workflow](../../../.github/workflows/p4-research-terraform.yml) executes `terraform fmt -check -recursive`, `terraform init -backend=false`, `terraform validate` without AWS credentials and explicitly forbids any apply/destroy action. **Do not run root `../main.tf` by default.**

Before an authorised real plan/apply: obtain explicit approval for account, regional provider pricing (default `eu-west-2`), unique bucket, existing reviewed OIDC-provider ARN, protected GitHub environment, remote state backend and retention/privacy policy. Use AWS Pricing Calculator. Athena is charged per data scanned; 1 GiB cutoff is *per query*, not a monthly budget. At an illustrative **$5/TB**, 100 maximum-size queries correspond to roughly 0.1 TB / **$0.50** of scan volume alone; this is **not a quoted actual bill**. S3 GB-month/versioned copies/reads/writes and query results, Glue metadata and CloudWatch may incur charges. Set AWS Budgets alerts (not hard caps) and avoid uploading data before approval. `force_destroy = false` prevents accidental nonempty bucket deletion; any teardown must be explicitly approved, preserving evidence, IAM roles and remote state.

Full operational production scope requires independently authorised OIDC, real role testing, secret management, provider endpoints, incident monitoring, encrypted audit retention and identity management. Human-review fraud scores remain synthetic and **are never an automated final judgement**.
