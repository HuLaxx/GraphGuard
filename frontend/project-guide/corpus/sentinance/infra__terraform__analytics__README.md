# Opt-in Sentinance AWS analytics sandbox (review only)

This independent Terraform root is the low-cost alternative to the legacy EKS/NAT/RDS/Redis design in ../main.tf. Run commands from **this directory**, not the parent. Existing local PostgreSQL/Kafka ingestion and verified immutable Parquet remain the data sources. This sandbox defines a private S3 bucket (versioning, SSE-S3, TLS-only policy, public access disabled), Glue metadata database, Athena named workgroup with 1 GiB per-query cutoff, and environment-bound GitHub OIDC role scoped to approved snapshot and query-result prefixes. The role is not an infrastructure apply role. No Lambda, EventBridge, live ingestion, schema registration, Secrets Manager or backend hosting is provisioned. This is a reviewable starting point, not a deployed cloud pipeline.

Data layout: snapshots/<snapshot_id>/raw/raw.parquet, validated/validated.parquet, curated/minute_bars.parquet and manifest.json. Use fixture datasets until data rights are verified. Catalog table registration/import and checksum-preserving upload require separate approved execution. Never expose the bucket or put AWS credentials into a frontend or GitHub repository.

Offline checks: terraform fmt -check -recursive; terraform init -backend=false -input=false; terraform validate. CI has no AWS credentials and does not plan or apply. Before a real plan, configure a reviewed remote state backend, unique bucket, region (default eu-west-2), valid existing GitHub OIDC provider and protected analytics-review GitHub environment with approval and branch restrictions. Obtain explicit cost/plan and deployment approval. Never apply the parent legacy template as part of this workflow. No production environment is accepted.

Cost worksheet: Athena on-demand = scanned TB × regional price; 100 queries capped at 1 GiB each have an upper scan-volume scenario of roughly 0.1 TB (before canceled queries, charges per minimum and retries). At an illustrative $5/TB, that is about $0.5 query scanning, **not** a bill forecast. Add regional S3 stored GB-month + writes/reads + versioned objects and query results, Glue catalog and CloudWatch charges. No always-on compute is created. No monthly hard cap: the per-query cutoff cancels excessive queries but repeated queries still cost money. Versioning retains old objects; review lifecycle for results and noncurrent versions with owner-approved retention, and set budget notifications before applying. See [Athena pricing](https://aws.amazon.com/athena/pricing/), [S3 pricing](https://aws.amazon.com/s3/pricing/), [Athena scan controls](https://docs.aws.amazon.com/athena/latest/ug/workgroups-setting-control-limits-cloudwatch.html). Validate region-specific rates with AWS Pricing Calculator. No account prices or actual costs have been measured.

Teardown requires review and separate authorization: inventory retained objects and versions, export evidence, explicitly approve deletion (force_destroy is false), then use the reviewed Terraform destruction plan. Do not delete production buckets, shared OIDC providers, or remote state. Nothing has been provisioned.
